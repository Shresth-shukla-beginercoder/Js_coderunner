# ⚒️ Code Forge 

link-: https://js-coderunner.onrender.com/

**Code Forge** is a JavaScript-focused online code runner designed not only to **run JavaScript code**, but also to help developers **understand what their code is doing**.

Unlike a traditional code runner, Code Forge combines code execution, output, error handling, and code explanations in one place.

---

## 🚀 Features

### 🟨 JavaScript Code Runner

Write and execute JavaScript directly in the browser.

* Run JavaScript code instantly
* View the program output
* Experiment with JavaScript syntax and logic
* Useful for learning, testing, and debugging

### 📤 Output Viewer

After executing your code, Code Forge displays the output in an easy-to-read format.

You can use it to understand:

* `console.log()`
* Variables
* Functions
* Loops
* Arrays and objects
* Return values
* Program behavior

### 🧠 Code Explanation

Code Forge is designed with learning in mind.

Instead of simply showing the result of your program, it can explain **what the code is doing** and help users understand the logic behind it.

This makes Code Forge useful for beginners who want to learn JavaScript by experimenting with their own code.

### ❌ Error Handling

Code Forge provides error information when JavaScript code fails to execute.

It can help users understand problems such as:

* Syntax errors
* Reference errors
* Type errors
* Invalid JavaScript
* Runtime errors

The goal is not just to show an error, but to make the error easier to understand.

### 💬 Prompt-Based JavaScript Assistance

One of the key features of Code Forge is its **prompt option**.

Users can provide a natural-language prompt along with their JavaScript code.

For example:

> "Explain why this loop is not producing the expected output."

or

> "Explain this JavaScript code step by step."

or

> "Help me understand this error."

This makes Code Forge different from a basic online code runner because users can interact with their code using **both code and natural-language prompts**.

## 🎯 Why Code Forge?

Most code runners primarily focus on one workflow:

```text
Write Code → Run Code → See Output
```

Code Forge aims to provide a more complete learning workflow:

```text
Write Code
     ↓
Run JavaScript
     ↓
See Output
     ↓
Check Errors
     ↓
Ask a Question / Give a Prompt
     ↓
Understand the Code
```

The goal is to make coding experimentation more interactive and educational.

## 💻 Example

A user could enter:

```javascript
let numbers = [1, 2, 3, 4, 5];

for (let i = 0; i < numbers.length; i++) {
    console.log(numbers[i] * 2);
}
```

Code Forge can execute the code and show:

```text
2
4
6
8
10
```

The user can then provide a prompt such as:

```text
Explain how this loop works.
```

The explanation can help the user understand how the loop accesses each array element and multiplies it by `2`.
